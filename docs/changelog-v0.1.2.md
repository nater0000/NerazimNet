# NerazimNet v0.1.2

## Fixes

- **Theme contrast**
  - Transparent buttons (sidebar nav, Cancel, Forgot Password, Generate Key
    Pair) now use the theme label color instead of the green-button text
    color — readable in both light and dark modes.
  - Segmented buttons and Settings tabs use a deeper green for the selected
    state so tab text stays legible on both selected and unselected segments.

## Version

- Bumped to 0.1.2.
