# NerazimNet v0.1.3

## Fixes

- **Dark-mode icons**
  - All toolbar/sidebar icons now have mint-tinted dark-mode variants in
    `resources/images/dark/`; the image loader picks them up automatically.
  - Colored icons (status dots, start/stop) keep their colors with a light lift.
- **Disabled/placeholder text**
  - Brightened to `#5A736E` (light) / `#7FA0A6` (dark) — muted but readable.

## Version

- Bumped to 0.1.3.
